# PresenterCursor (プレゼンテーション用マウスカーソル拡張アプリ)

PresenterCursorは、プレゼンテーション、デモンストレーション、画面共有、動画作成時にマウスカーソルやキーボード入力を視覚的に強調し、視聴者の視線を集めやすくするためのデスクトップ支援アプリケーションです。

---

## 💡 主な機能

- **スポットライト (`Ctrl + Shift + S`)**  
  カーソル周辺のみを円形に明るく照らし、それ以外の画面領域を暗くマスクします。Escキーで即座に解除できます。
  
- **エリアスポットライト (`Ctrl + Shift + A`)**  
  ドラッグで指定した任意の長方形の領域を切り抜いてハイライト表示します。Escキーで即座に解除できます。
  
- **レーザーポインター (`Ctrl + Shift + L`)**  
  カーソルの移動に伴って滑らかな赤い軌跡（レーザー跡）を描画します。

- **クリック波紋エフェクト**  
  クリックされた場所に視覚的な波紋（アニメーションリング）を表示し、クリック操作を分かりやすくします。

- **手書きマーカー（ペンモード） (`Ctrl + Shift + P`)**  
  画面上のあらゆる場所にフリーハンドで直接線を書き込むことができます。不透明度をスライダーで自由に変更可能です。
  - **一時的描画機能**: マーカーがONのとき、指定の「手書きトリガーキー」（Shift, Alt, Ctrl, Space）を押し続けている間は、クリックせずともマウスを動かすだけで描画可能です。
  - **アンドゥ・リドゥ**: 描いた線を1画ずつ元に戻す (`Ctrl + Shift + Z`)、やり直す (`Ctrl + Shift + Y`) ことができます。
  - **クリア**: 描いた線を一括で全消去 (`Ctrl + Shift + C`) します。

- **ズーム機能（拡大鏡） (`Ctrl + Shift + M`)**  
  カーソルの周囲を瞬時にズームインします。ズーム中はマウスホイールをスクロールすることで、シームレスに拡大倍率を調整できます。

- **タスクトレイ常駐化**  
  メインの設定画面ウィンドウを閉じても、アプリは終了せずタスクトレイ（通知領域）に常駐します。トレイアイコンの右クリックメニューやダブルクリックから、いつでも設定画面を再表示できます。

- **ワンクリック全機能OFF**  
  設定画面のヘッダーにある電源ボタンから、すべてのアシスト機能（ジェスチャーも含む）を一括で無効化できます。

## 🖱️ マウスジェスチャー操作 (中ボタン長押し)

マウスの中ボタン（ホイールクリック）を長押ししたまま特定のジェスチャーを描いてから離すことで、ショートカットキーを使わずに機能を操作できます。

| ジェスチャー | 割り当て機能 | 動作概要 |
| :--- | :--- | :--- |
| **✓ (V字を描く)** | 手書きペン ON/OFF | 手書きマーカーの有効/無効を切り替えます |
| **↔ (左右に細かく振る)** | 全機能OFF | 有効になっているすべてのアシスト機能を停止します |
| **← (右から左へスワイプ)** | アンドゥ (Undo) | 直前に手書きで描いた線を1画消去します |
| **→ (左から右へスワイプ)** | リドゥ (Redo) | 消去した手書きの線を1画復元します |

## ⌨️ デフォルトショートカットキー

| ショートカットキー | 機能 |
| :--- | :--- |
| `Ctrl + Shift + S` | スポットライトトグル |
| `Ctrl + Shift + A` | エリアスポットライト起動（ドラッグで範囲指定、Escで解除） |
| `Ctrl + Shift + L` | レーザーポインタートグル |
| `Ctrl + Shift + P` | 手書きペンモードトグル |
| `Ctrl + Shift + M` | ズーム（拡大鏡）モードトグル (ホイールで倍率変更) |
| `Ctrl + Shift + Z` | 手書きペン アンドゥ (戻る) |
| `Ctrl + Shift + Y` | 手書きペン リドゥ (やり直し) |
| `Ctrl + Shift + C` | 手書きペン 全クリア |
| `Esc` | スポットライト / エリアスポットライトの一斉解除 |

## 🛠️ 開発とビルド手順

### 必要な環境
- Node.js (Vite + Electron)
- Windows OS (グローバルインプット監視に `uiohook-napi` を使用しています)

### 1. 依存関係のインストール
```bash
npm install
```

### 2. 開発モードでの起動
フロントエンドのローカルサーバーとElectronメインプロセスが同時に立ち上がります。
```bash
npm run electron:dev
```

### 3. アプリケーションのパッケージング（ビルド）
ビルドが完了すると、`dist-electron` ディレクトリ内にインストール不要でダブルクリックするだけで使えるポータブル実行ファイル (`PresenterCursor 1.0.0.exe`) が生成されます。
```bash
npm run electron:build
```
※ アプリアイコンやトレイ用アイコンは、ビルド時に `scripts/make-ico.js` によって自動作成・更新されます。
